info A. Pengenalan INTERMILAN

INTERMILAN (Integrasi Rekonsiliasi Mandiri Laporan Keuangan) adalah aplikasi berbasis web yang dirancang untuk mempermudah dan mengotomatisasi proses rekonsiliasi dokumen keuangan (SPM, SP2D, DRPP, Kuitansi) pada satker BPS.

Tujuan Aplikasi

  • Mengurangi beban pencatatan manual oleh operator keuangan.
  • Menyediakan satu sumber kebenaran (Single Source of Truth) untuk status kelengkapan dokumen pencairan.
  • Menyimpan seluruh arsip dokumen (PDF) yang dapat ditelusuri seketika.

Fungsi Utama

  • Ekstraksi OCR: Membaca data langsung dari file PDF hasil scan.
  • Matching Otomatis: Mencocokkan SPM, DRPP, dan SP2D secara cerdas.
  • Monitoring Checklist: Mengetahui seketika dokumen mana yang belum lengkap.

Konsep Database D_K (Daftar Kuitansi)

D_K adalah tabel sentral (pusat/induk) dari seluruh transaksi. Setiap kali Anda memproses SPM atau DRPP, sistem akan menciptakan satu baris di D_K. Baris inilah yang kemudian akan "menunggu" dokumen pendukung lainnya (seperti SP2D atau Kuitansi) untuk dihubungkan hingga statusnya menjadi Lengkap.

upload_file C. Panduan Upload SPM

1. Persiapan File

Pastikan dokumen SPM (Surat Perintah Membayar) sudah di-scan dengan rapi dalam format PDF. Untuk mempercepat proses sistem, file jangan terlalu buram/gelap.

2. Cara Upload

  1. Buka menu Paket SPM & DRPP di sidebar kiri.
  2. Pilih tab SPM dan klik area upload (atau drag-and-drop file).
  3. Tunggu beberapa saat hingga mesin OCR mengekstrak teks dari PDF.

3. Cara Membaca Preview & Validasi Data

Setelah diupload, dokumen masuk ke tabel Preview SPM. Perhatikan kolom-kolomnya:

  • Nomor SPM: Pastikan terbaca benar. Jika salah baca, klik ikon edit untuk mengedit.
  • Nilai Netto & Bruto: Sistem akan berusaha memisahkan nilai. Periksa keakuratannya.

4. Penyimpanan

Jika SPM tersebut berdiri sendiri (contoh: LS Pihak Ketiga) dan bukan UP/GUP/TUP, Anda dapat menceklis baris tersebut, memilih aksi "Simpan ke D_K" dan menyelesaikannya. Dokumen aslinya akan langsung terlempar ke menu Arsip.

account_tree D. Panduan SPM Parent

Pengertian SPM Parent

SPM Parent adalah SPM Induk (biasanya jenis GUP, UP, TUP, atau PTUP) yang memiliki dokumen rincian turunan yang disebut DRPP (Daftar Rincian Permintaan Pembayaran).

Fungsi & Kapan Digunakan

Anda wajib menjadikan SPM sebagai Parent apabila SPM tersebut dilampiri oleh DRPP dan banyak Kuitansi. Jika langsung disimpan ke D_K tanpa dijadikan Parent, maka DRPP tidak akan bisa ditautkan ke SPM tersebut.

Langkah Menjadikan Parent

  1. Di tabel Preview SPM, ceklis baris SPM yang bersangkutan.
  2. Pada menu aksi di atas tabel, pilih "Simpan sebagai SPM Parent (Untuk DRPP)".
  3. SPM tersebut akan hilang dari Preview dan muncul di tab Parent SPM Aktif di sebelah kanan.

receipt_long E. Panduan Upload DRPP dan Kuitansi

1. Cara Upload DRPP

  1. Setelah Anda memiliki SPM Parent Aktif, masuk ke tab DRPP.
  2. Upload file scan PDF DRPP. Mesin akan membaca rincian per baris.

2. Memeriksa Balance (Keseimbangan)

Setelah DRPP diekstrak, akan muncul tabel rincian transaksi (per Akun/Kuitansi). Di bagian atas tabel DRPP, perhatikan indikator BALANCE. Total dari rincian DRPP harus klop/sama dengan total pada SPM Parent. Jika tidak balance, cek apakah ada baris yang nominalnya salah terbaca oleh OCR dan perbaiki.

3. Cara Upload Kuitansi

Pada DRPP yang sedang di-preview, terdapat kolom File Kuitansi. Anda bisa mengklik tombol upload kuitansi pada baris masing-masing rincian, atau me-drag banyak file kuitansi sekaligus ke area Dropzone utama.

4. Linking ke SPM Parent & Simpan ke D_K

  1. Pilih SPM Parent dari dropdown Pilih Parent SPM.
  2. Klik tombol Hubungkan untuk menautkan DRPP ke SPM Parent.
  3. Jika sudah terhubung dan DRPP sudah _balance_, klik tombol Simpan DRPP ke D_K.
  4. Sistem akan menyatukan DRPP, Kuitansi, dan SPM Parent menjadi transaksi D_K yang lengkap dan memasukkan seluruh file fisik ke dalam Arsip.

description F. Panduan Upload SP2D

Fungsi SP2D

SP2D (Surat Perintah Pencairan Dana) digunakan sebagai alat verifikasi final bahwa SPM yang diinput sebelumnya telah disetujui dan dicairkan oleh KPPN. INTERMILAN akan menggunakan data SP2D untuk melengkapi dokumen di D_K.

Proses Import & Format Excel

  1. Buka menu Upload SP2D.
  2. Siapkan file SP2D yang diunduh dari aplikasi perbendaharaan dalam format Excel (.xlsx) atau CSV.
  3. Pilih periode Bulan.
  4. Upload file tersebut.

Sistem Matching Cerdas

  • Matching Nomor SPM: Sistem mengabaikan huruf tambahan di belakang nomor (contoh: SP2D bernomor 00166T otomatis akan cocok dengan D_K bernomor 00166A).
  • Matching Satker: Sistem secara cerdas akan mencocokkan kode 4-digit satker Anda (misal `1300`) dengan kode resmi Kemenkeu 6-digit (`019937`). Anda tidak perlu mengubah apapun di file Excel.

Status SP2D pada D_K

Jika SP2D sukses terbaca, maka pada menu D_K, status transaksi akan berubah dari "Belum Ada SP2D" menjadi "Memiliki SP2D Pembanding" atau Terhubung.

table_chart G. Panduan Database D_K

Database D_K adalah jantung pelaporan Anda. Di sini Anda bisa melihat keseluruhan status dokumen secara terpadu.

  • Pencarian & Filter: Anda dapat memfilter berdasarkan Bulan, Akun, Satker (untuk role Admin), dan Status Kelengkapan. Ketik kata kunci pada kotak Search untuk mencari nomor SPM spesifik.
  • Checklist: Setiap baris memiliki kolom SP2D, SPM, Kuitansi, SPP, dll dengan indikator ADA atau TIDAK.
  • Detail Transaksi: Klik pada "Nomor SPM" untuk membuka laci geser (Off-canvas) di sebelah kanan. Anda dapat mengedit rincian manual atau menambahkan link dokumen Google Drive pada laci ini.
  • Status Kelengkapan: Jika semua checklist dokumen wajib terpenuhi, statusnya akan berubah menjadi LENGKAP berwarna hijau.

folder_open H. Panduan Arsip

Setiap dokumen PDF/Image yang Anda proses dan simpan ke D_K (baik itu SPM, DRPP, atau Kuitansi) tidak akan hilang. Dokumen tersebut akan bermuara di menu Arsip / Drive Link.

  • Hubungan Arsip dan Transaksi: Setiap file di Arsip ditautkan langsung ke Nomor SPM/Transaksi spesifik.
  • Pencarian Dokumen: Anda dapat mengetik nama file atau nomor SPM pada kolom pencarian Arsip untuk mendownload/melihat ulang dokumen kapan saja.
  • Integrasi Cloud: Sistem secara otomatis mengamankan file Anda dan membuatkan link penyimpanan yang terintegrasi (Google Drive integration).

build I. Troubleshooting

Masalah Penyebab Kemungkinan Solusi
Data SPM/DRPP tidak masuk ke Menu D_K Anda baru melakukan upload, tetapi belum memilih aksi "Simpan ke D_K". Pilih dokumen di tabel Preview (ceklis), lalu gunakan tombol aksi "Simpan ke D_K".
Upload file PDF gagal atau Macet File terlalu besar atau berpassword. Pastikan file PDF di bawah 5MB dan tidak dipassword/encrypted. Coba refresh halaman.
DRPP tidak terbaca / Nominal nol (0) Kualitas scan dokumen sangat buram, miring, atau kotor. Gunakan fitur edit (ikon pensil) pada tabel Preview untuk mengetik angka yang benar secara manual. Pastikan scan berikutnya lebih terang.
SP2D Excel ditolak dengan pesan error "invalid satker_code" Nomor satker pada Excel tidak dikenali oleh sistem pemetaan. Buka file Excel, pastikan kolom satker terisi dengan kode 4-digit satker (misal 1300) atau 6-digit resmi (019937) Anda secara presisi.
SP2D tidak cocok / tidak terhubung Nomor SPM di D_K dan SP2D berbeda sepenuhnya. Buka Menu D_K, edit transaksi dan pastikan Nomor SPM angka depannya sama persis (misal 00166) dengan SP2D.
Nomor SPM berbeda A/T di akhir (contoh: 00166A vs 00166T) Perbedaan format internal BPS dan KPPN. Tidak perlu khawatir, sistem akan otomatis mencocokkan (Smart Suffix Matching) angka 00166 tanpa huruf tambahan.
Satker berbeda 4 digit (1300) dan 6 digit (019937) Dua format kode satker yang berbeda. Sistem INTERMILAN sudah melakukan mapping otomatis. Anda tidak perlu mengubah 1300 menjadi 019937.
Data dianggap duplikat (Error Upload) Sistem mendeteksi Nomor SPM yang sama persis sudah pernah disimpan. Jika Anda ingin memperbarui, hapus data D_K yang lama terlebih dahulu, lalu upload ulang. Atau ganti nomor SPM jika memang berbeda.

help J. FAQ (Pertanyaan yang Sering Diajukan)

1. Apa yang harus dilakukan jika saya salah upload file? expand_more
Jika file masih berada di tabel Preview, Anda cukup menceklisnya lalu klik "Hapus Terpilih". Jika sudah masuk ke D_K, masuk ke menu D_K, hapus transaksinya, lalu hapus dokumennya di menu Arsip.
2. Apakah INTERMILAN wajib digunakan setiap hari? expand_more
Sangat disarankan mengunggah dokumen secara real-time / harian (segera setelah SPM/SP2D terbit) agar mempermudah monitoring dan tidak menumpuk di akhir bulan.
3. Mengapa tombol "Simpan DRPP ke D_K" dinonaktifkan (disabled)? expand_more
Tombol hanya aktif jika Anda telah (1) Menghubungkan DRPP ke Parent SPM, dan (2) Indikator BALANCE di bagian atas tabel bernilai "Match".
4. SPM saya nomornya '00166A' tetapi SP2D bernomor '00166T'. Apakah akan error? expand_more
Tidak. INTERMILAN memiliki teknologi "Smart Suffix Matching". Sistem akan cerdas mengenali bahwa angka intinya (00166) sama dan mengabaikan huruf di belakangnya secara otomatis.
5. Bolehkah saya langsung menyimpan SPM jenis UP/TUP ke D_K tanpa Parent? expand_more
Secara teknis bisa, tetapi sangat tidak disarankan karena Anda akan kehilangan kemampuan melacak dan menautkan rincian kuitansi/DRPP yang akan menyusul kemudian ke SPM tersebut.
6. Berapa batas ukuran maksimal file PDF? expand_more
Batas maksimal per file yang disarankan adalah 5 MB untuk kelancaran ekstraksi sistem.
7. Kenapa setelah upload DRPP, beberapa nominal terdeteksi '0'? expand_more
Hal ini terjadi bila kolom nominal di kertas PDF tertimpa stempel, coretan pulpen, atau hasil scan terpotong. Silakan ubah angka tersebut manual melalui ikon pensil (edit).
8. Apakah saya bisa mengupload file gambar Kuitansi (JPG/PNG)? expand_more
Ya. Menu Upload DRPP/Kuitansi mendukung file PDF maupun Image (JPG, PNG). Namun PDF lebih disarankan untuk multi-halaman.
9. Saya mendapat warning "Nomor SPM Duplikat". Apa maksudnya? expand_more
INTERMILAN memproteksi agar satu Satker tidak memasukkan dua SPM dengan nomor yang sama di tahun yang sama. Pastikan Anda tidak mengupload dokumen yang sama dua kali.
10. Bagaimana cara memperbaiki Nomor SP2D yang salah di D_K? expand_more
Buka tabel D_K, klik pada Nomor SPM yang bersangkutan, lalu pada laci rincian di sisi kanan, klik tombol "Edit". Perbaiki nomornya lalu Simpan.
11. Apa bedanya SPM dan DRPP? expand_more
SPM adalah surat perintah pembayaran (induk), DRPP adalah rincian permintaan pembayaran (anak/rincian).
12. Bagaimana jika saya lupa menghubungkan Parent? expand_more
Data DRPP akan tersimpan lepas (yatim piatu) di D_K dan tidak akan masuk hitungan nominal SP2D secara terpadu.
13. Dimana saya melihat Kuitansi yang sudah diupload? expand_more
Bisa melalui laci detail di menu D_K (klik nomor SPM) atau menu Arsip / Drive Link.
14. Apakah data saya aman? expand_more
Ya, dokumen Anda dienkripsi dan diamankan menggunakan integrasi Google Drive yang dilindungi berlapis.
15. Jika D_K sudah LENGKAP (hijau), apa yang selanjutnya dilakukan? expand_more
Anda tidak perlu melakukan apa-apa. Dokumen telah selesai terekonsiliasi dan diarsip permanen.
16. Bagaimana cara mengganti Password Akun? expand_more
Hubungi administrator pusat untuk pengubahan konfigurasi password satker.
17. Dapatkah saya menghapus SP2D yang salah import? expand_more
Bisa. Hubungi Admin (Role Admin) untuk menghapus riwayat import SP2D dari backend.
18. Apa itu Status "Perlu Review" di D_K? expand_more
Artinya masih ada dokumen pendukung (checklist) yang kosong / belum lengkap (misalnya belum ada Kuitansi).
19. Kenapa menu D_K saya kosong padahal satker lain ada isinya? expand_more
Karena sistem menerapkan Isolasi Data (Data Privacy). Anda hanya bisa melihat transaksi milik satker Anda sendiri.
20. Apakah bisa mencari SPM berdasarkan nominal Uang? expand_more
Tentu. Gunakan kotak Search di atas tabel D_K, dan ketikkan nominal yang dicari.
21. Mengapa nama Satker di Excel saya berubah jadi angka 6 digit di sistem? expand_more
Itu adalah konversi ke Kode Resmi Kementerian Keuangan. Aplikasi otomatis merapikannya.
22. Bisa tidak export D_K ke Excel? expand_more
Ya, gunakan tombol "Export" yang disediakan pada menu D_K jika hak akses Anda mencukupi.
23. Apa arti indikator "Unbalance" warna merah saat upload DRPP? expand_more
Total DRPP yang terdeteksi OCR tidak sama dengan total SPM Parent yang Anda pilih.
24. Jika Uang Bruto dan Netto tertukar saat scan, apa efeknya? expand_more
Nantinya akan terjadi ketidaksesuaian saat rekonsiliasi SP2D. Segera edit via ikon pensil di Preview.
25. SP2D saya CSV bukan Excel, apakah bisa? expand_more
Bisa. Sistem mensupport format modern .xlsx maupun .csv.
26. Bisakah saya membatalkan aksi "Simpan ke D_K"? expand_more
Aksi simpan tidak bisa di-Undo, tetapi Anda bisa menghapus datanya di tabel D_K secara manual dan mengulang dari awal.
27. File PDF saya halamannya terbalik, apakah masih terbaca? expand_more
Tergantung kemiringan. Sistem memiliki Auto-Rotation ringan, tapi usahakan scan dokumen dalam posisi tegak lurus.
28. Apakah aplikasi bisa diakses di Handphone? expand_more
Bisa, antarmuka INTERMILAN sudah dirancang responsif, meskipun upload dokumen besar lebih disarankan via PC/Laptop.
29. Kuitansi saya ada 50 lembar, haruskah upload satu per satu? expand_more
Tidak perlu. Jadikan satu file PDF (scan massal), lalu upload ke kolom "File Pendukung Utama" DRPP.
30. Kemana saya harus melapor jika ada Bug / Error tak terduga? expand_more
Hubungi Administrator BPS Provinsi dengan menyertakan _screenshot_ pesan error dan langkah-langkah yang Anda lakukan.
